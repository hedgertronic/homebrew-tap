# hedgertronic/tap

Homebrew casks and formulas for apps and tools by [hedgertronic](https://hedgertronic.com/).

| | Install |
| --- | --- |
| [Snug](https://snugshot.app), screenshots that fit like a glove | `brew install --cask hedgertronic/tap/snug` |

Snug updates itself, so `brew upgrade` leaves it alone; `brew uninstall --cask snug` removes it, and `--zap` its settings and caches too.
